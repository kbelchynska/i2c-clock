# Модуль 4.3. I²C годинник

**ESP32-S3-DevKitM-1** зчитує час з RTC **DS1307** і показує його на OLED **SSD1306 128×64**:

```
        15:33:59          ← HH:MM:SS, шрифт ×2
   Sat 14.02.2026         ← EEE DD.MM.YYYY
```

Обидва пристрої на одній шині I²C. Драйвери написані на `Wire` без сторонніх бібліотек.

## Підключення

| Модуль         | SDA   | SCL   | VCC  | GND |
|----------------|-------|-------|------|-----|
| ESP32-S3       | GPIO8 | GPIO9 | —    | GND |
| SSD1306 (0x3C) | SDA   | SCL   | 3.3V | GND |
| DS1307 (0x68)  | SDA   | SCL   | 5V   | GND |

DS1307 працює лише від 4.5–5.5 В (при 3.3 В він переходить на батарею і не відповідає по I²C).
Високий рівень I²C для нього ≥ 2.2 В, тому шина на 3.3 В підходить. Якщо на RTC-модулі
є підтяжки SDA/SCL до його VCC (5 В), їх слід прибрати — піни ESP32 не толерантні до 5 В.

## Як працює

1. `initI2C()` — `Wire` на 100 кГц.
2. `initDisplay()` — послідовність ініціалізації SSD1306 (0xAE … 0xAF) одним кадром з control byte `0x00`.
3. `initRtc()` — якщо біт CH (осцилятор зупинено) встановлений, записується час компіляції.
4. `readTime()` — 7 регістрів DS1307 (0x00–0x06), BCD → двійкові.
5. `updateDisplay()` — малювання в буфер 1024 байти, потім передача в GDDRAM (`0x21`/`0x22` + дані з `0x40`).

RTC опитується кожні 200 мс, екран перемальовується при зміні секунди — тобто щосекунди.

Час можна виставити з Serial Monitor (115200): `2026-02-14 15:33:59`. День тижня рахується автоматично.
